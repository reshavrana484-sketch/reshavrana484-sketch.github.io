🧐 What is ASIJI?

ASIJI-Native-Rust-Player is a free, open-source media player that lives right inside your computer's terminal (command prompt). It transforms your music and movie watching into a visually exciting experience by converting audio and video into live ASCII art and half-block graphics.

Who is this for? Whether you're a casual music fan, an old-school tech enthusiast, or someone who loves cool visuals while listening to albums, ASIJI is built to be easy—just download, double-click, and enjoy. No programming experience required.

Platform Support: Made for Windows 10/11 and Linux.

✨ Amazing Features

🎵 Music Player

Play all your favorite audio files (MP3, FLAC, WAV, and more) with rich, animated waveform visualizers that pulse with the beat.

🎥 Video in ASCII

Watch videos as real-time ASCII art in your terminal! A fun, retro experience that turns movies into living pixel art.

🎨 Half-Block Video

Get sharper, more detailed video playback using clever half-block characters for a crisper image while keeping the retro vibe.

📊 Reactive Visualizers

Multiple visualizer modes—bars, waves, circular, and spectrum—all responding to your music in real-time to create an immersive experience.

⚡ Blazing Fast

Built entirely in Rust, the application starts instantly and uses minimal system resources. Even on old machines, you get smooth playback.

🖥️ Works in Terminal

No fancy GUI needed—just open your terminal (Command Prompt, PowerShell, Windows Terminal, or any Linux terminal) and run it. Lightweight and powerful.

📋 What You'll Need

Operating System: Windows 10 or newer, or any modern Linux distribution (Ubuntu, Fedora, Debian, etc.).

Terminal: Any standard terminal application already installed on your system (Command Prompt, PowerShell, Windows Terminal, GNOME Terminal, Konsole, etc.).

Storage Space: Approximately 50 MB of free disk space.

Memory (RAM): 512 MB or more is recommended for smooth performance.

💡 Note: The player uses ffmpeg to handle media files. If you have any audio or video files not playing correctly, simply install ffmpeg on your system following the simple instructions on their website.

🔧 Quick Troubleshooting

File won't play? Make sure the file is in a common format (like .mp3, .wav, .mp4, .avi, .flac). If you're having issues, try converting the file to a more standard format.

Colors look weird? Some terminals have limited color support. Try using Windows Terminal (Windows) or GNOME Terminal (Linux) for the best experience.

Can't open the program? Right-click the downloaded file and select "Run as administrator" if nothing happens when you double-click.
